# VR Player - 手机 VR 盒子全景播放器 (Android 原生工程)

专为**手机 VR 盒子（Cardboard / VR 眼镜 / 头戴头盔）**深度打造的高性能 VR 视频播放器原生工程源码。

## 🌟 核心功能与 VR 盒子针对性优化

### 1. 完善的界面控制体系 (补充齐全)
- **顶部功能栏 (Top Bar)**：
  - **📁 片源选择 (`btnSource`)**：
    - 支持系统文件选择器打开手机本地存储视频（相册、Download、文件管理中的 MP4、MKV、WebM 等）；
    - 支持网络串流 / 局域网 HTTP 直链输入播放；
    - 内置 4 套不同格式的 VR 体验示范样片。
  - **🌐 VR 格式切换 (`btnVRFormat`)**：
    - `360° 单目全景 (Mono 360)`
    - `360° 左右 3D (SBS 360)`
    - `180° 左右 3D (VR180 SBS)`
    - `3D 左右 巨幕影院 (Cinema 3D SBS)`
    - `2D 弧面巨幕影院 (Cinema 2D)`
  - **🥽 双目分屏 (`btnToggleSplit`)**：一键切换手机普通单屏模式与双目立体分屏 (Side-by-Side) 模式。
  - **🧭 陀螺仪体感 (`btnToggleGyro`)**：实时跟随头部晃动转动全景视角，支持随时开关。
  - **🔒 视角锁定 (`btnLockView`)**：卧姿或移动环境下可一键锁死视角，避免误晃。
  - **🎯 归中复位 (`btnRecenter`)**：戴上头显后一键将画面正向对齐至当前面部方向。
  - **👁 瞳距调校 (`btnToggleIpd`)**：呼出毫米级瞳距微调卡片。
  - **💡 屏幕常亮 (`btnKeepAwake`)**：保障观影途中不熄屏、不锁屏。

### 2. 手机 VR 盒子专属校准与微调
- **毫米级瞳距 (IPD) 调节**：
  - 支持 `[-1mm]` 与 `[+1mm]` 步进微调；
  - 提供 `58mm 窄瞳距`、`64mm 标准`、`70mm 宽瞳距` 快捷预设档位；
  - 像素级滑动条精确补偿不同 VR 盒子镜片的光学偏轴。
- **光学中心瞄准线与准星 (`crosshairOverlay`)**：
  - 屏幕正中心高亮垂直中缝线，方便将手机精准放置在 VR 盒子正中卡槽；
  - 左右眼中心交叉十字准星，方便透过透镜校准视线焦点。
- **4 秒无操作自动隐藏 (Auto-Hide)**：
  - 单击屏幕呼出/隐藏，4 秒未操作自动平滑淡出，避免放入 VR 盒子后按钮挡住画面。

### 3. 底部完整播放控制栏
- 大按键 **▶ 播放 / ⏸ 暂停**
- **⏪ -10s 快退** 与 **⏩ +10s 快进**
- 进度拖拽滑块与时间格式化显示 (`01:25 / 15:30`)
- **1.0x / 1.25x / 1.5x / 2.0x / 0.75x** 倍速播放
- 音量调节与快捷静音切换

### 4. 触控盲操手势 (戴上头显盲操作)
- **左半屏上下滑动**：无级调节屏幕亮度，带瞬时 HUD 显示；
- **右半屏上下滑动**：调节系统媒体音量，带瞬时 HUD 显示；
- **水平滑动**：快进 / 快退时间跳转，带秒数 HUD；
- **双指缩放**：调节视场角 FOV (45° ~ 110°)。

## 🛠 技术实现架构

- **语言**：Kotlin + AndroidX + ViewBinding
- **图形管线**：OpenGL ES 2.0
  - `SphereMesh.kt`：全景球体、180度半球顶、弧形巨幕 3 种几何体网格生成，着色器动态 UV 区域裁切（原生支持 SBS 左右眼分离硬解码绘制）
  - `VRRenderer.kt`：双目视口分割 (`glScissor`)、IPD 视口物理偏移、头部姿态旋转矩阵与手动拖拽平滑融合
- **视频解码**：Google 官方 `androidx.media3:media3-exoplayer:1.2.1`（MediaCodec 硬件加速）
- **传感器**：`Sensor.TYPE_ROTATION_VECTOR` 旋转矢量传感器

## 🚀 Android Studio 编译运行指南

1. 打开 **Android Studio**，点击 **Open...** 选择本解压目录；
2. 等待 Gradle 自动完成依赖同步 (Gradle Sync)；
3. 将安卓手机开启「开发者选项 - USB 调试」后连入电脑；
4. 点击上方工具栏绿色三角形 **Run 'app'** 即可直接编译安装至手机；
5. 打包正式安装包：点击顶部菜单 **Build > Build Bundle(s) / APK(s) > Build APK(s)**。
